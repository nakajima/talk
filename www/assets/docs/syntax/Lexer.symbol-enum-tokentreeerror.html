enum TokenTreeError

A delimiter-balance failure encountered while building token trees.

Cases

case unexpected_closer(Token)

A closing delimiter appeared with no open group.

case mismatched_closer(Token, Token)

A group closed with a different delimiter than it opened with.

case unclosed(Token)

Input ended while the opening delimiter was still unmatched.
