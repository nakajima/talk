func assert(_ condition: Bool) 'fail

Reports the default assertion message when condition is false.

Failure is resumable: execution continues after the assertion so one test can record multiple failures. The active test runner owns failure collection.

View Source
pub func assert(_ condition: Bool) 'fail {
	if !condition { 'fail(message: "assertion failed") }
}
