enum Documentable

A declaration or signature component stored in the flat documentation graph.

Top-level and member declarations reference separate entries for parameter, effect, generic, and type spellings. This preserves one source-ordered store while DocumentableID keeps references kind-checked.

Cases

case builtin(Builtin)

A compiler-provided type documented without a Talk declaration.

case function(Function)

A top-level function declaration.

case global(Global)

A top-level let declaration.

case method(Method)

A function declared inside a nominal type.

case nominal(Nominal)

A struct or enum declaration.

case property(Property)

A stored property declared inside a struct.

case type(Type)

A source-spelled type annotation or generic parameter.

case variant(Variant)

An enum case and its payload types.

case effect_declaration(EffectDeclaration)

A top-level effect declaration.

case effect(Effect)

An effect named by a function signature.

case parameter(Parameter)
