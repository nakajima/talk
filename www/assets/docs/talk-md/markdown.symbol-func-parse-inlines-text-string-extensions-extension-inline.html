func parse_inlines(text: &String, extensions: &[Extension]) -> [Inline]

Parses one inline-content span without applying block grammar.

Enabled extensions affect strikethrough and autolink recognition. Newlines are preserved as soft or hard break nodes, and disabled constructs remain text.
