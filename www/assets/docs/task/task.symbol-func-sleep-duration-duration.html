func sleep(_ duration: Duration) -> ()

Suspends until at least duration of monotonic time has elapsed.

The deadline is absolute, so spurious wakes simply recheck the clock. Non-positive durations return immediately.

View Source
pub func sleep(_ duration: Duration) -> () {
	let deadline = Instant.now().adding(duration)
	loop Instant.now() < deadline {
		'wait(reasons: [WaitReason.deadline(deadline)])
	}
}
